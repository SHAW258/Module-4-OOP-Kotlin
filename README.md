# Module 4 Kotlin OOP Solutions

Each question is a standalone Kotlin program with its own main() function. Run one .kt file at a time. Questions 9 and 10 intentionally define separate Shape examples (interface and abstract base class), so compiling all files together will create duplicate class names.

## Files

- Q01_Car.kt - Question 1: Car objects
- Q02_Student.kt - Question 2: Student introduction
- Q03_RectangleArea.kt - Question 3: Rectangle area
- Q04_BankAccount.kt - Question 4: Encapsulation and balance validation
- Q05_EmployeeSalary.kt - Question 5: Encapsulated salary
- Q06_AnimalDog.kt - Question 6: Animal and Dog inheritance
- Q07_PersonTeacherStudent.kt - Question 7: Person subclasses
- Q08_PlayableGames.kt - Question 8: Playable interface
- Q09_ShapeInterface.kt - Question 9: Shape interface
- Q10_ShapePolymorphism.kt - Question 10: Shape polymorphism
- Q11_AnimalPolymorphism.kt - Question 11: Animal polymorphism
- Mini_LibrarySystem.kt - Mini assignment: Library system

## Compile and run one example

From this folder, for example:

kotlinc Q01_Car.kt -include-runtime -d Q01_Car.jar
java -jar Q01_Car.jar

Replace Q01_Car.kt and Q01_Car.jar with the selected file and matching output JAR name.
